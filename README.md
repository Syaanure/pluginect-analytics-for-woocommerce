# Pluginect Analytics – Statistics & Reports for WooCommerce

Mesure d'audience, de ventes et de campagnes pour WooCommerce, sans service
tiers : les données restent sur le serveur.

**Version gratuite.** Fonctionne seule. L'extension
`pluginect-analytics-for-woocommerce-pro` s'y greffe pour les fonctions avancées, mais
n'est jamais nécessaire.

## État

Séparation Free / Pro en cours. Nom du dépôt provisoire.

Voir `FREE-PRO.md` à la racine du dépôt parent pour l'architecture, la répartition des
fonctionnalités et la procédure de construction.

## Prérequis

WordPress, WooCommerce, PHP 7.4+.
